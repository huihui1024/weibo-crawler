# 微博博主内容抓取应用

一个用于抓取微博博主内容并展示的应用。

## 功能特性

- 支持配置多个微博博主，每个博主可设置独立的采集频率
- 自动定时抓取微博内容
- 支持图片下载和本地存储
- 支持转发微博的完整展示
- 正确处理置顶微博，避免重复采集
- 博主删除/隐藏微博后，历史数据仍然保留
- Web界面查看历史数据

## 安装

```bash
# 进入项目目录
cd weibo_crawler

# 安装依赖
pip install -r requirements.txt
```

## 配置

编辑 `config.yaml` 文件，添加要监控的博主：

```yaml
bloggers:
  - uid: "1234567890"        # 微博用户ID
    nickname: "博主A"         # 显示名称
    interval: 30             # 采集间隔(分钟)
    enabled: true            # 是否启用
```

**如何获取微博UID：**
1. 打开微博移动版页面 `https://m.weibo.cn`
2. 进入博主主页
3. URL格式为 `https://m.weibo.cn/u/1234567890`，其中数字就是UID

## 运行

```bash
python run.py
```

或使用 uvicorn：

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000 查看界面。

## 使用说明

### 博主管理

1. 访问"博主管理"页面
2. 输入微博UID和昵称
3. 设置采集间隔（建议不少于10分钟，避免被封）
4. 点击"添加博主"

### 查看历史

1. 在首页点击"查看历史"
2. 浏览该博主的所有已采集微博
3. 支持分页浏览

### 手动爬取

- 在首页点击"立即爬取全部"可手动触发所有博主的爬取
- 在博主卡片点击"立即爬取"可单独爬取某个博主

## 注意事项

1. **请求频率**：建议采集间隔设置在30分钟以上，避免被微博反爬机制封禁
2. **登录限制**：本应用使用移动端公开接口，部分内容可能需要登录才能查看
3. **数据保留**：博主删除或隐藏微博后，已采集的历史数据仍会保留
4. **图片存储**：图片会下载到本地，占用磁盘空间
5. **API限制**：微博可能对未登录用户限制访问，如果爬取失败，请尝试：
   - 增加采集间隔（建议60分钟以上）
   - 使用已登录的Cookie（需要在代码中配置）
   - 等待一段时间后再试

## 常见问题

### Q: 爬取返回0条数据？
A: 微博API有访问限制，可能原因：
- 请求过于频繁，被临时封禁
- 需要登录才能查看博主内容
- 该博主没有公开微博

解决方法：
- 等待一段时间后重试
- 增加采集间隔时间
- 尝试其他公开博主

### Q: 如何获取微博UID？
A: 
1. 打开微博移动版 m.weibo.cn
2. 搜索或进入博主主页
3. URL格式为 `m.weibo.cn/u/1234567890`，数字即为UID
