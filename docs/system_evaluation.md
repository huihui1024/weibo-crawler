# 智能荐股系统 — 技术评估文档

> 版本: v2.0 | 日期: 2026-06-12 | 评估对象: 系统功能完整性、逻辑合理性、数据准确性

---

## 一、系统概述

本系统是一个面向A股市场的智能荐股系统，核心定位为**短线波段交易辅助决策工具**（持仓周期1-4周）。系统从微博博主分析、市场热点追踪、多因子量化评分三个维度生成推荐，并通过持仓跟踪、质量反馈闭环持续优化。

### 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                     用户交互层                           │
│  Web界面(FastAPI)  |  CLI命令行  |  REST API(40+端点)    │
├─────────────────────────────────────────────────────────┤
│                     决策引擎层                           │
│  选股引擎 → 组合构建 → 交易决策 → 持仓跟踪 → 质量反馈     │
├─────────────────────────────────────────────────────────┤
│                     分析模型层                           │
│  多因子模型(6因子) | IC衰减监控 | 自适应策略 | 风险度量    │
├─────────────────────────────────────────────────────────┤
│                     数据采集层                           │
│  新浪HTTP API | 腾讯HTTP API | AkShare | efinance(东方财富) │
├─────────────────────────────────────────────────────────┤
│                     存储层                               │
│  SQLite(26张表) | 本地文件(图片/日志)                     │
└─────────────────────────────────────────────────────────┘
```

## 二、核心功能模块

### 2.1 选股引擎（stock_selector.py）

**选股流程**：三来源采集 → 4层漏斗筛选 → 动态加权评分 → 来源分配 → 准入门槛

#### 2.1.1 股票来源与名额分配

| 来源 | 名额占比 | 数据来源 | 当前胜率 |
|------|----------|----------|----------|
| 市场热点 | 60% | 涨幅榜 + 热门概念板块 | ~11%（近期市场下跌） |
| 行业方向 | 25% | 博主关注板块 + 关键词匹配 | ~10% |
| 量化确认 | 15% | 龙虎榜 + 机构调研 + 量价策略 | ~10% |

**来源优先级逻辑**：
- 市场热点为主导来源，行业方向和量化确认仅作交叉确认
- 非热点股票如果同时出现在热点中 → 加分15%并改标为市场热点
- 未被热点确认的非热点股票 → 降权30%
- 博主关注板块与市场热点方向一致 → 该股票权重+20%

**热点新鲜度机制**：

| 涨幅 | 新鲜度评分 | 处理方式 |
|------|-----------|----------|
| ≥5% | 100（极新鲜） | 入选，composite×1.1 |
| 3-5% | 80（新鲜） | 正常入选 |
| 1.5-3% | 60（观察） | 正常入选 |
| 0.5-1.5% | 30（衰减） | 不取成分股 |
| <0.5% | 10（明显衰减） | 跳过 |

**准入门槛**：composite_score < 0.3（z-score尺度）的股票不推荐，宁缺毋滥。

#### 2.1.2 四层漏斗筛选

| 层级 | 功能 | 方法 | 当前状态 |
|------|------|------|----------|
| L1 | 基本面排除 | ROE<5%、营收<-20%、OCF<0且ROE<8% 排除 | 排除法（不加分） |
| L2 | 估值评分 | PE/PB 3年百分位，越低分越高 | 正常 |
| L3 | 资金流评分 | 主力资金净流入评分 | 正常 |
| L3.5 | 认知差评分 | 博主认知领先/机构覆盖真空 | 正常 |
| L4 | 情绪增强 | 市场情绪指标 | 正常 |
| L4.5 | 产业链推理 | 瓶颈节点/定价权分析 | 正常 |

#### 2.1.3 动态加权评分

各因子经winsorize + z-score标准化后，按市场状态加权求和：

| 因子 | 牛市 | 震荡市 | 熊市 |
|------|------|--------|------|
| 估值 | 15% | 20% | 25% |
| 资金流 | 30% | 25% | 15% |
| 认知差 | 12% | 12% | 10% |
| 情绪 | 20% | 15% | 10% |
| 产业链 | 23% | 28% | 40% |

**注意**：基本面(fundamental_score)已从加权评分中移除，仅作为L1排除条件使用。

### 2.3 IC衰减监控（ic_decay_monitor.py）

| 阈值 | 动作 |
|------|------|
| IC连续2周 < 0.02 | 降权（原权重×0.5） |
| IC连续2周 < 0 | 暂停（原权重×0.1） |

**健康度等级**：healthy → watch → degraded → suspended

| 参数 | 牛市策略 | 震荡市策略 | 熊市策略 |

### 2.5 交易决策引擎（trading_decision.py）

#### 买入时机判定

```
时机评分 = 技术面得分×0.4 + 资金面得分×0.35 + 因子面得分×0.25
```

- 时机评分 ≥ 70 发出买入信号
- 评分 ≥ 85 为高置信度，仓位满配
- 评分 75-85 七成配，70-75 半配

#### 卖出决策（四类信号）

| 类型 | 优先级 | 触发条件 |
|------|--------|----------|
| 止损/止盈 | immediate | 触发策略预设价格 |
| 信号反转 | normal | 基本面/技术面信号反转 |
| 时间衰减 | watch | 持仓超预期周期2倍且涨幅<3% |
| 机会成本 | watch | 出现更优标的 |

### 2.6 持仓跟踪状态机（position_tracker.py）

```
observing → ready_to_buy → bought → holding → sold
                ↓              ↓          ↓
            超时降级(3天)   次日转holding  止损/止盈/移动止损
```

| 状态 | 含义 | 转换条件 |
|------|------|----------|
| observing | 观察期，时机评分<70 | 评分≥70 → ready_to_buy |
| ready_to_buy | 待买入，时机评分≥70 | 手动确认 → bought |
| bought | 已买入（当日） | 次日自动 → holding |
| holding | 持有中 | 触发止损/止盈/移动止损 → sold |
| sold | 已卖出 | 终态 |
| expired | 超时降级 | ready_to_buy 3天未执行 → expired |

### 2.7 推荐质量反馈闭环（recommendation_feedback.py）

**质量评分公式**：

```
质量分 = 方向准确度×0.4 + 幅度准确度×0.3 + 时机准确度×0.3
```

- 方向准确度：预期涨实际也涨=100分，否则0分
- 幅度准确度：max(0, 100 - |实际-预期|×10)
- 时机准确度：实际持仓天数/预期持仓天数

**质量等级**：A(≥80) / B(≥60) / C(≥40) / D(≥20) / F(<20)

**自动降级阈值**（看最近10条推荐）：

| 条件 | 触发动作 |
|------|----------|
| 方向准确率 < 50% | 系统降级为degraded |
| 胜率 < 40% | 系统降级为degraded |
| 平均质量 < 40 | 系统标记为watch |
| 平均幅度偏差 > 5% | 系统标记为watch |

质量反馈结果自动写入`get_dynamic_win_rate()`的信号强度判断。

### 2.9 风险度量（risk_metrics.py）

| 指标 | 方法 |
|------|------|
| VaR | 历史模拟法 / 参数法 / Monte Carlo / Cornish-Fisher |
| CVaR | 条件VaR（Expected Shortfall） |
| 夏普比率 | (年化收益-无风险利率) / 年化波动率 |
| 索提诺比率 | 仅计算下行波动率 |
| 卡玛比率 | 年化收益 / 最大回撤 |
| 最大回撤 | 峰谷法 |
| 压力测试 | 4情景（暴跌-15%/急涨+20%/闪崩-25%/长期低迷-10%/月） |

## 七、关键风险评估

### 7.1 准确性问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 实盘胜率43.9% << 回测64% | **严重** | 回测存在过拟合/前视偏差，回测胜率不可信 |
| 方向准确率17.2% | **严重** | 低于33%的随机水平，模型可能在系统性做反 |
| 所有来源胜率均<15% | **严重** | 无有效信号源，系统当前不应发出推荐 |
| 趋势因子IC=-0.495 | **高** | 趋势因子反向有效，说明A股短线趋势延续性差 |
| 北向资金IC=-0.047 | **中** | 北向资金跟随效应不显著或已衰减 |

### 7.2 数据质量问题

### 7.3 逻辑问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 4层漏斗的L3.5认知差评分 | **中** | 依赖博主分析，博主信号已降权但认知差仍占12%权重 |
| L4.5产业链推理 | **中** | 数据来源单一，推理逻辑未经验证 |
| composite_score的z-score标准化 | **低** | 样本量小(<30)时z-score不稳定 |
| 热点新鲜度基于当日涨幅 | **低** | 无法区分第1天热点和第3天热点（仅靠涨幅近似） |

## 八、改进建议（按优先级）

### P0 — 紧急（当前系统不应发出推荐）

1. **暂停所有推荐输出**：胜率43.9%、方向准确率17.2%，系统当前处于suspended状态是正确的，不应解除
2. **排查方向准确率17.2%的根因**：低于随机水平意味着模型可能在系统性做反，需检查是否存在信号反转或数据前视偏差
3. **回测引擎审计**：64%回测胜率与43.9%实盘胜率的巨大差距，需排查回测中的前视偏差/幸存者偏差/过拟合

### P1 — 重要（1-2周内）

4. **趋势因子反转**：IC=-0.495意味着趋势反转信号比趋势延续更有效，应将趋势因子改为反向因子
5. **增加择时维度**：当前系统选股能力强于择时，需增加大盘择时模块（决定是否应该持仓）
6. **热点新鲜度需要历史数据**：仅靠当日涨幅无法判断热点第几天，需记录板块连续涨幅天数

### P2 — 改进（1个月内）

7. **基本面排除法需要更多维度**：当前仅ROE/营收/OCF，应增加商誉占比、质押率、审计意见等
8. **产业链推理需要数据验证**：当前推理逻辑基于规则，缺乏实际数据支撑
9. **模拟交易需要自动执行**：当前止损信号依赖人工执行，应实现模拟盘自动止损

### P3 — 长期

10. **券商API对接**：实现从推荐到执行的闭环
11. **多市场一致性**：港股/美股模块与A股模块逻辑对齐
12. **机器学习增强**：用ML模型替代部分规则因子（需足够样本量）

## 附录：信号强度判定逻辑

```
1. 动态胜率判定：
   - 连续5天胜率<50% → suspended
   - 实盘胜率与回测偏差>15% → suspended
   - 连续3天胜率<50% → degraded
   - 偏差>10% → degraded

2. 质量反馈叠加：
   - 质量报告system_health=degraded → normal降为degraded
   - 质量报告system_health=degraded且已degraded → 升级为suspended
   - 质量报告system_health=suspended → 直接suspended

3. 信号强度影响：
   - suspended: composite_score × 0.5, 最多推荐5只
   - degraded: composite_score × 0.75, 推荐数量减半
   - normal: 正常推荐

4. 强制风险警告（未满3个月模拟）：
   - 所有推荐附带"请勿直接跟投"警告
   - API响应包含simulation_warning字段
   - CLI显示模拟进度横幅
```
