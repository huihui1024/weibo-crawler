# 智能选股与复盘系统 — 技术白皮书

> 版本: v2.0 | 更新日期: 2026-06-11 | 面向对象: 资深投资分析师

---

## 一、系统概述

本系统是一个面向A股市场的**智能选股 + 预测 + 复盘闭环**平台，核心目标是将博主投资策略与量化市场信号融合，生成次日走势预测，并通过每日复盘验证预测准确性、形成反馈闭环。

### 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                     Web 控制台 (FastAPI)                  │
│   股票池 | 预测记录 | 复盘报告 | 风险度量 | 回测          │
└───────────┬────────────────────────────────┬────────────┘
            │                                │
   ┌────────▼────────┐              ┌───────▼────────┐
   │   选股引擎       │              │   复盘引擎       │
   │ (3来源+4层漏斗)  │              │ (趋势+振幅+评分) │
   └────────┬────────┘              └───────┬────────┘
            │                                │
   ┌────────▼────────┐              ┌───────▼────────┐
   │   预测引擎       │◄────反馈─────│   反馈调节器     │
   │ (规则+ML双模型)  │              │ (偏差修正)       │
   └────────┬────────┘              └────────────────┘
            │
   ┌────────▼────────────────────────────────────────┐
   │              数据层                               │
   │  新浪财经 | 东方财富(akshare) | 腾讯K线 | LLM      │
   └──────────────────────────────────────────────────┘
```

### 核心流程（每日循环）

| 时段 | 任务 | 说明 |
|------|------|------|
| 09:15 | 选股 | 生成股票池 + 次日预测 |
| 14:50 | 复盘 | 验证前一日对今日的预测 |
| 15:30 | 预测更新 | 收盘后补充数据，触发反馈调节 |
| 每15s | 价格更新 | 实时更新股票池价格 |

## 二、选股引擎

### 2.1 三大股票来源

系统从3个独立来源获取候选股票，确保多元化：

| 来源 | 优先级 | 数据源 | 单次上限 | 机制 |
|------|--------|--------|---------|------|
| **博主策略** | 最高(0) | akshare板块成分股 | 15只 | 根据博主仓位配置比例选股 |
| **系统推荐** | 中(1) | akshare量化策略 | 9只 | 5个主流量化策略（见下文） |
| **市场热点** | 低(2) | akshare概念+涨幅榜 | 6只 | 热门概念成分股 + 涨幅榜筛选 |

**名额分配**: 博主策略50%、系统推荐30%、市场热点20%，某来源不足时名额自动释放给其他来源。

### 2.2 系统推荐 — 5个量化策略

| # | 策略名称 | akshare接口 | 核心筛选条件 | 逻辑 |
|---|---------|-------------|-------------|------|
| 1 | 龙虎榜机构净买入 | `stock_lhb_stock_statistic_em` | 机构买入净额>0 & 上榜次数≥3 | 机构资金认可 = 价值发现 |
| 2 | 机构调研热度 | `stock_jgdy_tj_em` | 接待机构数量≥20 | 机构密集调研 = 关注度上升 |
| 3 | 强势股(涨停新高) | `stock_zt_pool_strong_em` | 60日新高 & 换手率<20% | 突破新高 = 趋势确认 |
| 4 | 连续量价齐升 | `stock_rank_ljqs_ths` | 量价齐升天数≥3 | 量价配合 = 最可靠趋势信号 |
| 5 | 涨停池 | `stock_zt_pool_em` | 连板≥2 或 首板+行业热门 | 跟踪市场最强方向 |

所有策略均排除 ST/*ST/退市股，每个策略独立 try/except 包裹，单个策略失败不影响其他。

### 2.3 四层漏斗筛选

候选股票经过4层（+2个子层）量化漏斗：

```
全部候选 → L1 基本面 → L2 估值 → L3 资金流 → L3.5 认知差 → L4 情绪 → L4.5 产业链 → 最终股票池
```

#### L1: 基本面硬筛选
| 条件 | 阈值 | 数据源 |
|------|------|--------|
| ROE_TTM | > 8% | akshare `stock_a_lg_indicator` |
| 营收增长率 | > 0% | akshare 利润表 `stock_financial_report_sina` |
| 经营性现金流 | > 0 | akshare 现金流量表 |

超时保护: 单只股票5秒，总计120秒，超时用默认值50分通过。

#### L2: 估值百分位评分
- 计算PE/PB的3年百分位（akshare `stock_a_lg_indicator` 历史数据）
- 评分公式: `100 - (PE百分位 × 0.6 + PB百分位 × 0.4)`
- 百分位越低 → 估值越便宜 → 分越高

#### L3: 资金流评分
- 北向资金持股变化 + 5日净流入
- 数据源: akshare `stock_hsgt_individual_em` / `stock_individual_fund_flow`
- 评分基于北向资金趋势和个股资金净流入比例

#### L3.5: 认知差因子
| 维度 | 逻辑 | 评分影响 |
|------|------|---------|
| 市值分组 | <50亿+25分, 50-200亿+15分, 200-500亿+5分 | 小市值 = 机构难以覆盖 |
| 博主提及频次 | ≥5次+15分, ≥3次+10分, ≥1次+5分 | 频次高 = 博主认知领先 |
| 研报覆盖度 | 0篇+10分, ≤2篇+5分, ≥10篇-5分 | 无研报 = 机构认知真空 |
| 来源加分 | 博主策略+10分 | 博主讨论 = 认知优势 |

#### L4: 情绪增强
- 博主看空/已清仓 → 降级到30%水平
- 博主策略但无仓位(position_weight=0) → 降级到60%水平
- 正常情绪评分 = 风格匹配度

#### L4.5: 产业链推理
基于产业链知识图谱，发现瓶颈节点（具有定价权的公司）:

```
GPU/算力 → 互联带宽(瓶颈) → 光模块/CPO → 激光器散热(瓶颈) → ELS/CW光源
锂电池 → 正极/负极/电解液/隔膜 → 锂矿供应(瓶颈)
光伏 → 硅料/硅片/电池片/组件 → 硅料产能(瓶颈)
```

- 处于瓶颈节点 + 认知差高 → 双重加分(+15分)
- 支持LLM增强推理（当硬编码图谱无法覆盖时）

### 2.4 因子标准化与动态加权

**标准化流程**: Winsorize(1%/99%) → Z-score标准化

**市场状态检测** → 动态权重分配:

| 因子 | 牛市 | 熊市 | 震荡市 |
|------|------|------|--------|
| 基本面 | 10% | 25% | 18% |
| 估值 | 8% | 22% | 18% |
| 资金流 | 25% | 8% | 17% |
| 认知差 | 15% | 10% | 15% |
| 情绪 | 25% | 15% | 15% |
| 产业链 | 17% | 20% | 17% |

牛市重资金流和情绪，熊市重基本面和估值，震荡市均衡分配。

**IC检验**: 系统自动运行因子IC检验（信息系数），剔除无效因子、增强有效因子权重。

### 2.5 看涨过滤

预测生成后，过滤掉预期无涨幅的股票:
- 移除 `expected_close_change ≤ 0` 的股票
- 移除趋势为"横盘震荡"、"震荡下跌"、"弱势下跌"的股票
- 仅保留预测有涨幅的股票进入最终股票池

## 三、预测引擎

### 3.1 双模型架构

系统采用**ML模型优先 + 规则引擎降级**的双模型架构:

```
输入股票代码
    │
    ├─ ML模型可用? ──→ RandomForest分类+回归 ──→ 输出预测
    │   (15个技术因子特征)
    │
    └─ ML模型不可用 ──→ 规则引擎 ──→ 输出预测
        (均线系统+成交量+资金流)
```

### 3.2 ML模型 — RandomForest

**模型类型**: 双模型（分类模型判方向 + 回归模型估幅度）

**特征工程** — 15个技术因子:

| # | 特征名 | 含义 |
|---|--------|------|
| 1 | return_1d | 当日涨跌幅 |
| 2 | return_5d | 5日累计涨跌幅 |
| 3 | return_10d | 10日累计涨跌幅 |
| 4 | ma5_ratio | close/MA5 - 1 |
| 5 | ma10_ratio | close/MA10 - 1 |
| 6 | ma20_ratio | close/MA20 - 1 |
| 7 | ma_cross | 均线多头排列编码(0-3) |
| 8 | volatility_5d | 5日收益率标准差 |
| 9 | volatility_20d | 20日收益率标准差 |
| 10 | volume_ratio | 当日量/MA5量 |
| 11 | rsi_14 | 14日RSI |
| 12 | macd_signal | MACD信号方向(-1,0,1) |
| 13 | amplitude | 当日振幅 |
| 14 | volume_change | 量变化率 |
| 15 | price_position | 价格在20日高低区间位置 |

**训练**: 时间序列切分(前80%训练/后20%验证)，避免未来信息泄漏。
**数据源**: 腾讯K线API，60日历史数据。

### 3.3 规则引擎 — 趋势分析

当ML模型不可用时，降级到规则引擎:

**趋势判断** (基于均线系统):

| 条件 | 趋势 | 预期涨跌幅 |
|------|------|-----------|
| close > MA5 > MA10 > MA20 | 强势上涨 | +2.0% |
| close > MA5 & close > MA20 | 震荡上涨 | +1.0% |
| close < MA5 < MA10 < MA20 | 弱势下跌 | -1.5% |
| close < MA5 | 震荡下跌 | -0.8% |
| 其他 | 横盘震荡 | 0.0% |

**修正因子**:

| 修正项 | 逻辑 | 影响 |
|--------|------|------|
| 成交量 | 放量(>50%)上涨时 ×1.3 | 放量确认趋势 |
| 市场情绪 | sentiment_factor(基于大盘涨跌) | 强势+1.3, 中性1.0, 弱势×0.7 |
| 资金流向 | 主力净流入>3% ×1.1, <-3% ×0.9 | 资金确认 |
| 近3日动量 | 近3日涨>5% ×0.6(回调压力) | 防止追高 |
| 复盘反馈 | 基于近5日预测偏差调整sentiment_factor | 自适应修正 |

**振幅预测** (基于ATR+历史振幅):
```
base_amplitude = ATR × 0.4 + 历史平均振幅 × 0.6
最终振幅 = max(历史最小振幅×0.9, min(base_amplitude×趋势调整, 历史最大振幅×1.5))
```

### 3.4 持股周期预测

| 博主交易周期 | 建议持有天数 | 日均收益(上涨趋势) |
|-------------|-------------|-------------------|
| 超短线 | 2天 | +0.5%/天 |
| 短线 | 5天 | +0.5%/天 |
| 波段 | 15天 | +0.5%/天 |
| 中长线 | 60天 | +0.5%/天 |

下跌趋势: -0.3%/天; 震荡: +0.2%/天

## 四、复盘引擎

### 4.1 每日复盘流程

```
前一日预测 ──→ 获取今日实际走势 ──→ 逐条对比 ──→ 生成复盘报告
                    │
          ┌─────────┴─────────┐
          │                   │
     新浪实时行情          K线历史数据
```

### 4.2 趋势匹配判定

| 预期趋势 | 实际趋势 | 匹配规则 |
|---------|---------|---------|
| 强势上涨 | 强势上涨 | 直接匹配 |
| 震荡上涨 | 上涨/震荡上涨 | 方向一致即匹配 |
| 横盘震荡 | 横盘震荡/微涨(≤1%)/微跌(≥-1%) | ±1%视为横盘 |
| 震荡下跌 | 下跌/震荡下跌 | 方向一致即匹配 |
| 弱势下跌 | 弱势下跌/下跌 | 直接匹配 |

**容错**: 横盘震荡与微涨/微跌(±1%内)互相匹配; 上涨方向内各子类别互相匹配。

### 4.3 预测评分 (0-100分)

| 维度 | 权重 | 计算方式 |
|------|------|---------|
| 趋势匹配 | 40% | 匹配=40分, 不匹配=0分 |
| 涨跌幅偏差 | 30% | max(0, 30 - |偏差| × 10) |
| 振幅偏差 | 30% | max(0, 30 - |偏差| × 8) |

### 4.4 反馈闭环

复盘结果驱动两个自适应调节:

**1. 偏差修正** (`FeedbackAdjuster`):
- 统计近5日各因子(情绪/趋势/动量)的系统性偏差
- 例: 情绪因子持续偏乐观 → 自动降低sentiment_factor
- 修正系数存入 `feedback_adjustments` 表，预测引擎下次自动读取

**2. 因子权重调整**:
- 基于IC检验结果动态调整因子权重
- 无效因子(IC绝对值<0.03)降权，有效因子(IC>0.1)增权

### 4.5 历史表现

| 指标 | 数值 |
|------|------|
| 复盘总次数 | 25次 |
| 趋势匹配准确率 | 64.2% (95/148) |
| 平均涨跌幅偏差 | -0.10% (轻微偏低) |
| 平均振幅偏差 | 0.88% |

## 五、风险度量

### 5.1 组合风险报告

基于Modern Portfolio Theory，计算股票池组合级风险:

| 指标 | 方法 | 说明 |
|------|------|------|
| VaR | 历史模拟法 + 参数法 + Cornish-Fisher | 95%置信度下的最大损失 |
| CVaR | 历史模拟法 | 超过VaR的平均损失 |
| Sharpe Ratio | (组合收益-无风险利率)/波动率 | 风险调整后收益 |
| Sortino Ratio | (组合收益-无风险利率)/下行波动率 | 只考虑下行风险 |
| Max Drawdown | 峰值-谷值/峰值 | 最大回撤 |
| Calmar Ratio | 年化收益/最大回撤 | 收益/回撤比 |

### 5.2 压力测试

模拟极端市场场景下的组合表现:
- 牛市冲击(+5%)
- 熊市冲击(-5%)
- 黑天鹅事件(-10%)
- 流动性危机(-15%)

### 5.3 风险评级

| VaR% | 风险等级 | 风险评分 |
|------|---------|---------|
| <2% | 低风险 | 20-40 |
| 2-5% | 中风险 | 40-60 |
| 5-10% | 高风险 | 60-80 |
| >10% | 极高风险 | 80-100 |

### 7.5 数据源容错

系统采用**弹性客户端**(`ResilientClient`)架构:
- 新浪/腾讯直连(优先) → efinance(备用) → akshare(兜底)
- 自动重试3次，失败切换下一个数据源
- 请求限流: 最小间隔0.5秒，避免被封
- 超时保护: 各层筛选均有总时间上限(L1: 120s, L2: 60s, L3: 60s, L3.5: 60s, L4.5: 60s)

## 十一、系统局限性

### 11.1 数据层面

| 问题 | 影响 | 严重程度 |
|------|------|---------|
| akshare依赖爬取，接口不稳定 | 部分策略可能获取不到数据 | 中 |
| 新浪实时行情有频率限制 | 高频调用可能被封IP | 中 |
| 财务数据更新滞后(T+1至T+3) | 基本面筛选可能基于旧数据 | 低 |
| 920xxx代码(北交所)数据不全 | 3只北交所股票无法预测 | 低 |

### 11.2 策略层面

| 问题 | 影响 | 严重程度 |
|------|------|---------|
| 预测偏短期(次日)，缺乏中期趋势判断 | 不适合中长线投资者 | 中 |
| ML模型分类准确率42%偏低 | 方向判断不可靠，需结合规则引擎 | 高 |
| 振幅预测偏差较大(平均0.88%) | 买卖点建议参考价值有限 | 中 |
| 博主策略单一化(仓位集中于少数板块) | 股票池偏集中，分散化不足 | 中 |
| 产业链图谱覆盖有限(硬编码) | 非主流板块推理能力弱 | 低 |

### 11.3 架构层面

| 问题 | 影响 | 严重程度 |
|------|------|---------|
| 多因子评分计算耗时(30只~5分钟) | 选股刷新较慢 | 低 |
| 无实时推送(轮询15秒) | 价格更新有延迟 | 低 |
| 单博主依赖 | 策略多样性受限 | 中 |
| 无多市场对冲机制 | 组合风险无法对冲 | 中 |

## 十二、评估建议

基于以上分析，建议从以下维度评估系统:

1. **选股覆盖度**: 3来源+5策略的股票池是否足够多元化
2. **预测准确性**: 64.2%趋势匹配率是否达到可用标准
3. **因子有效性**: IC检验结果是否支持当前因子权重分配
4. **风险控制**: VaR+压力测试是否充分覆盖尾部风险
5. **反馈闭环**: 复盘→反馈→调整的自适应机制是否有效降低预测偏差
6. **数据可靠性**: akshare/新浪的数据质量和稳定性是否满足生产要求
7. **可扩展性**: 系统是否支持新增数据源、策略、市场的扩展
