> 版本: v2.0 | 日期: 2026-06-12 | 供资深投资分析师评估

## 一、系统概述

本系统是一个A股/港股/美股多市场智能荐股系统，核心逻辑为「择时优先于选股」。系统不依赖单一信号源，而是通过大盘择时判定市场环境、4层漏斗量化筛选、多因子动态评分、组合风控构建，输出经过风险预算的推荐标的池。

**设计原则：先定能不能做，再选做哪些股。**

### 1.1 系统架构

```
微博爬虫 → 博主分析器 → 行业方向参考（非主导）
                              ↓
行情数据源 → 大盘择时(5档) → 股票池生成 → 4层漏斗筛选 → 组合构建 → 风险预算
                              ↓               ↓              ↓           ↓
                          全面做空=禁止建仓  基本面排除    仓位截断    CVaR约束
                          谨慎做空=减半池子  估值百分位    板块分散    压力测试
```

### 1.2 核心模块清单

| 模块 | 文件 | 职责 |
|------|------|------|
| 大盘择时 | `selector/market_timing.py` | 基于沪深300判定5档市场环境 |
| 选股引擎 | `selector/stock_selector.py` | 股票池生成、4层漏斗、因子加权 |
| 多因子模型 | `selector/multi_factor_model.py` | IC筛选后的5因子评分 |

| 交易决策 | `selector/trading_decision.py` | 买入时机评估、止损止盈 |

## 二、大盘择时模块（最高优先级）

择时模块在选股之前运行，直接决定「能不能做」和「怎么做」。

### 2.1 五档择时等级

| 等级 | 标签 | 股票池比例 | 总仓位上限 | 单票上限 | 允许纯热点 | 最低综合分 |
|------|------|-----------|-----------|---------|-----------|-----------|
| `full_long` | 全面做多 | 100% | 85% | 5% | 是 | 0.20 |
| `cautious_long` | 谨慎做多 | 80% | 60% | 4% | 是 | 0.30 |
| `neutral` | 震荡 | 60% | 40% | 3% | 是 | 0.30 |
| `cautious_short` | 谨慎做空 | 40% | 15% | 2% | 否 | 0.50 |
| `full_short` | 全面做空 | 20% | 10% | 2% | 否 | 0.80 |

### 2.2 择时判定逻辑

基于沪深300指数的5个维度评分：

| 维度 | 指标 | 评分规则 |
|------|------|---------|
| 趋势方向 | MA5 vs MA20 vs 收盘价 | 多头排列 +2, 空头排列 -2 |
| 均线斜率 | MA5近5日变化率 | >2%:+1, 0~2%:+0.5, <-2%:-1 |
| 量能配合 | 近1日成交量 / 近5日均值 | 上涨放量:+1, 上涨缩量:-0.5, 下跌放量:-1 |
| 5日涨跌幅 | 近5日指数涨跌 | >3%:+1, 0~3%:+0.3, <-3%:-1 |
| 20日涨跌幅 | 近20日指数涨跌 | >8%:+1, <-8%:-1 |

评分→等级映射：≥4→全面做多, ≥2→谨慎做多, ≥-1→震荡, ≥-3→谨慎做空, <-3→全面做空

### 2.3 择时对选股的影响

- **全面做空**：`generate_candidate_pool()` 直接返回空列表，禁止建仓
- **谨慎做空/全面做空**：屏蔽纯热点题材股，仅保留基本面+龙虎榜双认证标的
- **所有等级**：`adjusted_max = max(3, max_stocks × pool_ratio)`，覆盖原始名额分配
- **组合截仓**：组合构建后，总仓位/单票仓位按择时上限截断

## 三、选股引擎（4层漏斗）

### 3.1 股票池来源与名额分配

| 来源 | 名额占比 | 说明 |
|------|---------|------|
| 市场热点 | 60% | 唯一有效来源，胜率67%（回测） |
| 行业方向 | 25% | 博主分析的行业方向参考，仅交叉确认 |
| 量化确认 | 15% | 多因子模型独立推荐，仅交叉确认 |

**交叉确认规则**：
- 市场热点 + 行业方向一致 → 权重+20%
- 非热点但被热点确认 → 权重+15%，改标为「市场热点」
- 未被市场热点确认 → 降权至70%

### 3.2 热点生命周期

每只热点股标记三阶段生命周期：

| 阶段 | 条件 | 综合分影响 |
|------|------|-----------|
| 启动(launch) | freshness≥80 且 概念日涨幅>3% | ×1.15 提权 |
| 发酵(ferment) | freshness≥50 或 概念日涨幅>0% | 不变 |
| 尾声(ending) | freshness<50 或 概念日涨幅<0% | ×0.3 大幅降权 |

### 3.3 L0 热点生命周期标记

在4层漏斗之前，对所有候选股标记热点生命周期阶段。来自概念板块日涨幅排行和涨幅榜。

### 3.4 L1 基本面排除法

L1不用于选股加分，仅排除财务有问题的股票。排除条件（任一满足即排除）：

| 排除条件 | 阈值 | 风险类型 |
|---------|------|---------|
| ROE < 5% | 盈利能力严重不足 | 盈利风险 |
| 营收增长 < -20% | 营收大幅下滑 | 成长风险 |
| OCF < 0 且 ROE < 8% | 现金流为负且盈利弱 | 现金流风险 |
| 质押率 > 50% | 大股东质押比例过高 | 流动性风险 |
| 商誉占净资产 > 30% | 商誉减值风险 | 资产质量风险 |
| 非标审计意见 | 财务可信度存疑 | 治理风险 |

通过L1的股票，`fundamental_score`统一设为50（中性），不参与后续加权。L1全部淘汰时回退保留所有候选。

**超时保护**：总时间>120秒或单票>5秒则跳过基本面检查，设为50分通过。

### 3.5 L2 估值百分位评分

基于PE/PB 3年历史百分位：
- 百分位越低 = 越被低估 = 分越高
- 超时保护>60秒则批量用默认值50

### 3.6 L3 资金流因子

基于龙虎榜、主力净流入等资金数据评分。

### 3.7 L3.5 认知差因子

识别市场定价真空：小市值+低机构覆盖+行业方向参考。权重已降至2%（因IC低）。

### 3.8 L4 情绪增强

市场情绪指标评分。

### 3.9 L4.5 产业链推理

基于LLM辅助的产业链推理（发现瓶颈节点/定价权）。权重已降至3-4%。

### 3.10 因子标准化与动态加权

**小样本处理**：候选<10只时，使用百分位排名替代z-score，映射到[-1,1]区间，避免极端值扭曲。

**大样本处理**：候选≥10只时，使用winsorize + z-score标准化。

#### 各市场状态下的因子权重

| 因子 | 牛市 | 熊市 | 震荡 |
|------|------|------|------|
| 估值(valuation) | 28% | 40% | 34% |
| 资金流(capital_flow) | 35% | 25% | 30% |
| 情绪(sentiment) | 32% | 29% | 30% |
| 认知差(cognitive_gap) | 2% | 2% | 2% |
| 产业链(chain_reasoning) | 3% | 4% | 4% |

**设计逻辑**：认知差+产业链合计≤6%（IC低），估值+资金流+情绪占比94%。

### 3.11 准入门控

- 最低综合分门槛 = max(0.3, timing_config['min_composite_score'])
- 择时走弱时门槛自动提高（谨慎做空需≥0.5，全面做空需≥0.8）
- 无股票通过门槛时，放宽至composite≥0

### 3.12 信号强度折扣

| 信号强度 | 触发条件 | 综合分折扣 |
|---------|---------|-----------|
| normal | 正常 | 无折扣 |
| degraded | 近期胜率<45% | ×0.75 |
| suspended | 连续10天低胜率或方向准确率<30% | ×0.5 |

## 六、风险度量体系

### 6.1 VaR计算

| 方法 | 说明 |
|------|------|
| 历史模拟法 | 基于历史收益分布 |
| 参数法(方差-协方差) | 假设正态分布 |
| 蒙特卡洛模拟 | 10,000次模拟 |
| Cornish-Fisher扩展 | 考虑偏度和峰度 |

置信水平: 95%

### 6.2 组合风险分析

| 指标 | 计算方式 |
|------|---------|
| 组合VaR | 基于持仓权重和协方差矩阵 |
| CVaR(条件VaR) | 超过VaR的期望损失 |
| 风险贡献度 | 各持仓的边际VaR贡献 |
| 夏普比率 | (组合收益-无风险利率) / 波动率 |
| 索提诺比率 | 仅考虑下行波动 |
| 最大回撤 | 峰值到谷底的最大跌幅 |
| Calmar比率 | 年化收益 / 最大回撤 |

### 6.3 压力测试场景

| 场景 | 假设 |
|------|------|
| 2015股灾 | 单日-8.5% |
| 2020疫情 | 单周-12% |
| 流动性危机 | 小盘股-15% |

### 6.4 风险监控

`RiskMonitor`持续检查风险限额，触发预警时输出告警。

## 七、回测引擎

### 7.1 回测修正（已审计项）

| 修正项 | 修正前 | 修正后 |
|-------|--------|--------|
| T+1对齐 | 当日买当日可卖 | 买入日≥卖出日时跳过 |
| 前视偏差 | 用close价买入 | 优先用next_open价 |
| 幸存者偏差 | 未排除ST/退市 | 跳过名称含ST/退的股票 |
| 移动止损 | profit_pct×1.2近似 | 跟踪实际peak_profit_pct |
| 滑点 | 未设置 | 默认0.1% |

### 7.2 回测输出指标

| 指标 | 说明 |
|------|------|
| total_return | 总收益率 |
| max_drawdown | 最大回撤 |
| sharpe_ratio | 夏普比率 |
| win_rate | 胜率 |
| profit_loss_ratio | 盈亏比 |
| total_trades | 总交易次数 |
| avg_hold_days | 平均持仓天数 |

### 7.3 回测胜率说明

系统回测基准胜率64%，但该数字存在以下局限：
- 回测环境未完全消除前视偏差（已修正但仍可能有残留）
- 样本期有限，不同市场状态下胜率差异显著
- 实盘验证尚未满3个月，实盘胜率可能偏离回测

## 八、模拟交易与自动止损止盈

### 8.1 模拟交易功能

- 基于实时行情的模拟撮合
- 支持滑点(默认0.1%)和手续费(最低5元)
- A股/港股/美股多市场支持

### 8.2 自动止损止盈

| 参数 | 默认值 |
|------|-------|
| 止损 | -5% |
| 止盈 | +10% |
| 最长持仓 | 20天 |

支持按股票自定义参数(`set_stop_params`)。

### 8.3 持仓风险预警子状态

| 状态 | 含义 |
|------|------|
| normal | 正常 |
| approaching_stop | 接近止损线(亏损达止损的60%) |
| approaching_exit | 接近最长持仓限制(剩余3天) |
| stop_loss_triggered | 止损触发，建议立即卖出 |
| take_profit_triggered | 止盈触发 |
| force_exit | 超过最长持仓天数，强制离场 |

### 8.4 质量反馈闭环

`RecommendationFeedback`模块对历史推荐进行事后审计：
- 自动获取推荐后N日的实际表现
- 计算方向准确率、收益偏差
- 生成质量报告(healthy/watch/degraded/suspended)
- 方向准确率<30%触发永久暂停

### 8.5 信号强度门控

| 信号强度 | 触发条件 | 影响 |
|---------|---------|------|
| normal | 默认 | 正常操作 |
| degraded | 近期胜率<45% | 推荐数量减半，综合分×0.75 |
| suspended | 连续10天低胜率或方向准确率<30% | 禁止建仓，返回冻结池 |

suspended状态下，系统暂停对外荐股输出，仅保留内部监控。解锁需人工审计。
